# Minesweeper



## **Visual Studio** 로 실행합니다

파일을 다운 받아 ``2023212581.sln`` 를 실행하여 주세요.


## 프로젝트 설명

난이도는 **1~3단계**로 나뉘어져 있습니다.

지뢰찾기의 **가독성**을 높히기 위해 판을 ``_|``로 반복하여 출력하였습니다.

![인터페이스](./지뢰찾기.png)

``system("cls");``를 사용하여 행동 할 때마다 터미널에 이전 행동들이 쌓이지 않게 깨끗이 지운 후 판을 출력합니다.

**flood_fill** 알고리즘을 활용하여 근처에 지뢰가 없는 칸을 클릭하면 근처의 지뢰 없는 칸을 전부 엽니다.
